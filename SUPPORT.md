# Support

Use GitHub Issues for open-source `snipara-companion` CLI problems:

- wrong or surprising `impact` output
- first-run or README confusion
- local workflow, context-pack, hook, or guard behavior
- focused parser/resolver improvements

Before opening an issue:

```bash
npx -y snipara-companion@latest --version
npx -y snipara-companion@latest impact <file> --source local
```

Do not post secrets, private source files, customer data, or full private logs.
Use reduced examples and redacted output.

Hosted Snipara features such as team memory, semantic retrieval, dashboards,
cloud code graph, account access, billing, and cross-machine sync are handled by
the hosted product support path, not this open-source CLI repository.
