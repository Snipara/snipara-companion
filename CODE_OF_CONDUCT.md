# Code of Conduct

This project should be practical, direct, and respectful.

## Expected Behavior

- Discuss ideas and tradeoffs without personal attacks.
- Keep issue reports focused on reproducible behavior and user impact.
- Redact secrets, private customer data, private repository output, and tokens.
- Assume maintainers may ask for a smaller repro before accepting a bug report
  or pull request.

## Unacceptable Behavior

- Harassment, threats, hate speech, or sustained personal attacks.
- Posting secrets, credentials, private keys, or private customer data.
- Spam, astroturfing, or repeated off-topic promotion.
- Demanding hosted/commercial product support in this open-source CLI repo.

## Enforcement

Maintainers may edit, hide, close, or delete comments and issues that violate
this code of conduct. Repeated or severe violations may result in a ban from
the repository.

If you need to report a conduct issue, use the most private maintainer contact
available to you. If no private channel is available, open a minimal GitHub
issue that avoids posting private details.
